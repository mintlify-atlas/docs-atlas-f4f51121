## Line-by-Line Breakdown

<Steps>
  <Step title="package main">
    ```go
    package main
    ```

    Every Go source file begins with a `package` declaration. The special name `main` tells the Go toolchain that this package is an **executable binary** rather than a reusable library. Without this declaration the file cannot be compiled into a runnable program.
  </Step>

  <Step title='import "fmt"'>
    ```go
    import "fmt"
    ```

    The `import` statement makes the `fmt` package available to the rest of the file. `fmt` is part of Go's **standard library** and provides functions for formatted I/O — including printing to stdout, reading from stdin, and formatting strings. Importing a package that is never used is a compile-time error in Go.
  </Step>

  <Step title="func main()">
    ```go
    func main() {
    ```

    `func main()` is the **program entry point**. When the compiled binary is executed, the Go runtime calls `main.main()` automatically. The function takes no arguments and returns no values; command-line arguments are accessed via `os.Args` if needed.
  </Step>

  <Step title='fmt.Println("Hello, 世界")'>
    ```go
    fmt.Println("Hello, 世界")
    ```

    `fmt.Println` writes its arguments to **stdout**, separated by spaces, and appends a trailing newline character (`\n`). The string literal `"Hello, 世界"` is valid UTF-8 — `世界` (meaning "world" in Chinese and Japanese) is encoded as a sequence of UTF-8 bytes and written to stdout as-is.
  </Step>
</Steps>

## fmt.Println Signature

```go

```

`Println` is a **variadic function** — it accepts any number of arguments of any type.

<ParamField body="a" type="...any">
  The values to print. Each argument is formatted using its default representation (equivalent to the `%v` verb). Multiple arguments are separated by a single space. In this program a single `string` literal is passed.

## Unicode in Go

Go source files are **always encoded as UTF-8**, and the language specification guarantees this. As a result:

- String literals can contain any Unicode code point directly — there is no need for escape sequences for non-ASCII characters such as `世界`.
- The `string` type in Go is an immutable sequence of **bytes**, not characters; iterating with `range` yields Unicode code points (`rune` values), not bytes.
- `fmt.Println` writes the **raw UTF-8 bytes** of a string literal directly to stdout. As long as the terminal or consuming process also uses UTF-8 encoding, the output will display correctly.

```go
// All three lines produce identical output
fmt.Println("Hello, 世界")
fmt.Println("Hello, \u4e16\u754c")   // Unicode escape sequences
fmt.Println("Hello, \xe4\xb8\x96\xe7\x95\x8c") // raw UTF-8 byte escapes
```

<Note>
  `fmt.Println` always appends a newline character (`\n`) after the last argument. If you want to print text **without** a trailing newline, use `fmt.Print` instead:

  ```go
  fmt.Print("Hello, 世界") // no newline appended
  ```
</Note>
