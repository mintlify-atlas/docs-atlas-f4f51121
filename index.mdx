## Get running in seconds

<Steps>
  <Step title="Install Go">
    Download and install Go 1.21 or later from [go.dev/dl](https://go.dev/dl/).
  </Step>
  <Step title="Clone the repository">
    ```bash
    git clone https://github.com/your-org/your-repo.git
    cd your-repo
    ```
  </Step>
  <Step title="Run the program">
    ```bash
    go run hello.go
    ```
    You should see `Hello, 世界` printed to your terminal.
  </Step>
</Steps>
