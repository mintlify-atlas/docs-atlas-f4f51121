## What Is your-repo?

**your-repo** is a minimal Go program whose sole purpose is to print `Hello, 世界` to standard output. The Chinese characters (世界) mean "world", making this the canonical multilingual twist on the classic Hello World example. The entire program lives in a single source file and has no external dependencies, making it an ideal starting point for anyone learning Go or setting up a new Go-based project from scratch.

```go
package main

import "fmt"

func main() {
	fmt.Println("Hello, 世界")
}
```

## Why It Matters

While the program is intentionally simple, it highlights two important characteristics of the Go programming language:

- **First-class Unicode support** — Go source files are UTF-8 by specification. String literals, identifiers, and I/O all handle multibyte Unicode characters without any extra configuration or third-party libraries.
- **Single-file simplicity** — A complete, runnable Go program can live in one file with no build configuration, no dependency manifest, and no boilerplate beyond the standard `package main` declaration and a `main` function.

These properties make Go approachable for newcomers while remaining practical for production-grade software.

<Note>
  Go mandates UTF-8 encoding for all source files and treats strings as
  arbitrary byte sequences that are conventionally UTF-8. The `fmt` package
  writes those bytes directly to stdout, so characters like 世界 are printed
  correctly on any UTF-8–capable terminal without any extra encoding steps.
</Note>
