This guide walks you through everything you need to get **your-repo** running on your machine. By the end you will have cloned the repository, executed the program, and produced a standalone binary — all using standard Go toolchain commands.

## Prerequisites

Before you begin, make sure the following tools are available on your system:

<Note>
  **Go 1.18 or later** is required. Download the latest stable release from
  [go.dev/dl](https://go.dev/dl) and follow the installation instructions for
  your operating system. Verify your installation with `go version`. You will
  also need **git** to clone the repository.
</Note>

## Steps

<Steps>
  <Step title="Clone the repository">
    Clone **your-repo** from GitHub and change into the project directory:

    ```bash
    git clone https://github.com/your-org/your-repo.git && cd your-repo
    ```
  </Step>

  <Step title="Run directly with go run">
    Use `go run` to compile and execute the program in a single command — no intermediate binary is written to disk:

    ```bash
    go run hello.go
    ```

    Expected output:

    ```
    Hello, 世界
    ```
  </Step>

  <Step title="Build a standalone binary">
    Use `go build` to compile the program into a reusable executable named `hello`:

    ```bash
    go build -o hello hello.go
    ```

    Run the resulting binary:

    ```bash
    ./hello
    ```

    Expected output:

    ```
    Hello, 世界
    ```
  </Step>
</Steps>

<Tip>
  `go run` compiles and executes your code in one step without leaving a binary
  on disk — perfect for quick iterations during development. Use `go build` when
  you need a standalone executable to distribute, deploy to a server, or run
  repeatedly without incurring compilation overhead.
</Tip>

## Both Approaches Side by Side

<CodeGroup>

```bash go run
go run hello.go
```

```bash go build
go build -o hello hello.go
./hello
```

</CodeGroup>
